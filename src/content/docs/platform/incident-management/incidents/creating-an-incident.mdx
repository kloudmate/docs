---
Use the following steps to create a new incident.

**Step 1:**Click on the**Create Incident** button located at the top-right corner of the screen.

![image](./images/creating-an-incident-1.jpeg)

**Step 2:**On the modal that appears, enter the**Title**and**Incident Details**. Use the**Select Severity** dropdown to set the severity level of your incident — Critical, High, Medium, or Low.

![image](./images/creating-an-incident-1.png)

**Step 3:**Use the**Select Integration**dropdown to attach the service integration the incident belongs to.**Step 4:**Select an**Escalation Policy**to override the default policy for this incident.**Step 5:**Click the**Create** button. Your incident will be created and displayed in the Incidents list.

![image](./images/creating-an-incident-2.png)

<hint type="info">
  **Note:** Selecting an integration is mandatory. If you don’t have an existing integration, you will need to create one first. See [Adding Integrations](../../integrations/adding-integrations/)

  If no escalation policy is selected, the escalation policy of the chosen integration will be applied to the incident.
</hint>
