Users can create multiple workspaces within KloudMate. You can use workspaces to group or isolate multiple data sources, for example, you can create separate workspaces for development, production, and more. KloudMate lets you view, add, delete, and edit **all the workspaces under one window.**

## Managing Workspaces

You will create your default workspace while [setting up your KloudMate](https://docs.kloudmate.com/setting-up-kloudmate) account. Once your KloudMate account is set up you can create multiple workspaces using the following steps:

- To view your workspaces and their respective details, click on **Settings > Workspaces**

![image](./images/workspaces-1.png)

- Click on the **Add Workspace** button located at the top right corner
- Enter your workspace name and click on submit

![image](./images/workspaces-2.png)

- Use the Edit option to change your workspace name or view its API key. Use the Delete button to permanently remove the workspace.

![image](./images/workspaces-3.png)

## Switching Workspaces

If you are a member of multiple workspaces within the same organization, you can switch between them using the workspace selector in the top‑right corner of the interface. Selecting a different workspace updates all views and data to that workspace.

![image](./images/workspaces-4.png)
