A Dashboards report emails PDF snapshots of one or more dashboards on a schedule. Each PDF shows the dashboard over the report's period, with the variable values you set when you [created the report](../create-report/#choose-a-source).

![A dashboard that a Dashboards report renders to PDF](./images/dashboard-report-1.png)

## What each run produces

Each run produces one PDF per dashboard. If you selected **Attach table panels as XLSX**, each dashboard also gets an XLSX file with a sheet for each table, logs, or spans panel.

## The report page

The report page lists the dashboards in the report. Select a dashboard's name to open it with the report's variable values applied.

![Dashboards report page with the Covers period in the header and the list of dashboards the report includes](./images/dashboard-report-2.png)

Click **Send Report now** to send the report right away, with a different period or different recipients if you need them. See [Send a report now](../#send-a-report-now).

## Download past files

Click **View Generated Reports** to download files from earlier runs. Each PDF and XLSX file from a run has its own row, and **Period Covered** shows the dates the file covers. See [Download generated reports](../#download-generated-reports).

![Generated Reports list for a Dashboards report, with a Period Covered column for each file](./images/dashboard-report-3.png)
