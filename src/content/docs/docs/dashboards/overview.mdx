title: Dashboards overview
description: Learn how to use KloudMate dashboards to visualise metrics, logs, and traces in one place.
---

KloudMate dashboards give you a customisable view of your observability data. You can combine metric charts, log panels, and trace summaries on a single screen.

## Dashboard features

- Drag-and-drop panel layout
- Template variables for dynamic filtering
- Shareable links and saved views
- Auto-refresh on configurable intervals

## Panel types

| Type | Description |
|---|---|
| Time series | Line or bar chart for metric data over time |
| Single stat | Display a single aggregated value |
| Log list | Show recent log entries matching a query |
| Trace list | Show recent traces matching a filter |
| Text | Static Markdown content for annotations |

## Prerequisites

- At least one data source connected
