The **Databases** page lists every database the KloudMate agent monitors, with its status, health, query load, and connections. Open an instance to see its metrics, the queries that take the most time, the sessions that are blocking each other, the services that call it, and where it sits in its replication cluster.

## Get your databases onto the page

A database appears on the **Databases** page after you set up monitoring for it in the KloudMate agent. You do this through a wizard: pick the engine, choose what to collect, and give the agent a monitoring user's credentials. See [Database monitoring overview](../kloudmate-agent/database-monitoring/overview/) for the setup, and [Engines and coverages](../kloudmate-agent/database-monitoring/engines-and-coverages/) for what each engine can collect.

What you see on an instance depends on the **coverages** you turned on for it in the wizard. For example, **Top queries** and **Query patterns** need the **Query performance (samples + top queries)** coverage, and **Topology** needs **Replication topology & lag**. When a tab has no data because a coverage is off, the tab tells you which coverage to turn on.

Some panels also need **Collect all optional metrics**, a setting on the database in the same wizard. Panels that depend on it are marked on the page.

The **Calling services** tab works from traces rather than from the database. It lists the services whose database calls appear as spans, whether those spans come from [eBPF monitoring](../kloudmate-agent/ebpf-observability/) or from OpenTelemetry instrumentation in your application.

## Supported engines

Every instance has an **Overview**, a **Metrics** dashboard, and a **Calling services** tab. The other tabs depend on the engine:

| Engine | Additional tabs |
|---|---|
| PostgreSQL, MySQL, MariaDB | Top queries, Query patterns, Running queries, Schema, Sensitive data, Topology |
| SQL Server | Top queries, Query patterns, Running queries, Schema, Sensitive data, Agent jobs, Topology |
| Oracle | Top queries, Query patterns, Running queries, Schema, Sensitive data, AWR, Topology |
| MongoDB | Top queries, Query patterns, Running queries, Collections, Sensitive data |
| Redis, ClickHouse | Topology |
| Elasticsearch, SAP HANA, MongoDB Atlas, Snowflake | None |

MariaDB instances are shown and handled the same way as MySQL.
