KloudMate provides native integrations for Microsoft Azure that allow you to seamlessly ingest platform metrics and logs into your observability pipelines. By connecting your Azure environment through Azure Monitor and Event Hubs, you can monitor your cloud infrastructure centrally without having to instrument every individual workload by hand.

## How it Works

KloudMate integrates with Azure using a Service Principal (an Azure AD application) that is granted specific read-only roles (such as `Reader`) to securely access Azure Monitor APIs. You can deploy this integration using an automated CLI script or configure it manually via a KloudMate Agent (an optimized OpenTelemetry Collector). For high-volume log ingestion, such as Application Gateway logs, KloudMate integrates directly with Azure Event Hubs.

## Key Capabilities

- **Azure Monitor Metrics**: Automatically scrape telemetry data from your Azure Monitor resources.
- **Automated or Manual Setup**: Choose between a fast, CLI-driven automated provisioning process or a manual configuration for full control over the collector.
- **Event Hub Integration**: Stream logs from Azure services (like Application Gateway) into KloudMate through Event Hubs for real-time analysis.
- **Secure Authentication**: Uses Azure AD Service Principals to ensure secure, least-privilege access.
