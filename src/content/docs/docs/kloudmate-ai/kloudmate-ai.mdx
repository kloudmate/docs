Introducing **K-AI**(or KloudMate's AI) quickly investigates issues or errors from logs and traces, summarizes their causes, and suggests probable root causes to speed up resolution. This feature significantly reduces **root cause analysis (RCA)** time for engineering teams.



### Decoding Issues with K-AI

The Issues section in KloudMate aggregates all errors and warnings detected from logs and traces into a unified dashboard view.
Navigate to any specific issue’s details page and click the “**Investigate with K-AI**” button for instant analysis.
K-AI decodes the issue context, explains what went wrong, and provides actionable steps for probable RCA, including potential service impacts.



### Analyzing Error Logs and Traces

The **Logs/Traces** page displays all ingested telemetry data with severity-based filtering to isolate errors quickly.
Select any error log or trace to open its details view, then use the “***Investigate with K-AI***” option.
K-AI analyzes the full context, including stack traces, attributes, and timestamps, to deliver an overview of the problem, its service impact, and step-by-step fix recommendations.



### Key Benefits

- **Faster Troubleshooting:** Real-time AI insights reduces MTTR by automating initial diagnostics.
- **Unified Visibility:** Correlates logs, traces, and issues without switching contexts.
- **Actionable Guidance:** Delivers plain-language root cause hypotheses and remediation steps for immediate use.
