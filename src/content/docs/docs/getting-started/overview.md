## What is KloudMate?

KloudMate is a unified observability platform that helps engineering teams monitor logs, metrics, traces, and synthetic checks from a single interface.

## Key features

- **Logs** — full-text search and structured log analysis
- **Metrics** — real-time charts and custom dashboards
- **Traces** — distributed tracing with root-cause analysis
- **Alerts** — flexible alert rules with multi-channel notifications
- **AI Assistant** — natural language queries over your observability data
- **Synthetic Monitoring** — proactive uptime and API testing

## How it works

KloudMate connects to your cloud infrastructure via lightweight agents or OpenTelemetry collectors. Data is ingested, indexed, and made available in the KloudMate console within seconds.

## Prerequisites

- A KloudMate account ([sign up](https://app.kloudmate.com/signup))
- Access to your cloud environment (AWS, GCP, Azure, or on-premises)
