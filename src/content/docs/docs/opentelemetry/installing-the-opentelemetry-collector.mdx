The OpenTelemetry Collector is a vendor-neutral service that receives, processes, and exports telemetry data. It is often the easiest way to standardize telemetry flow before sending data to KloudMate.

## When to Use the Collector

Using the Collector is not mandatory, but it is usually the best default. It is especially useful when you want to:

- Offload export work from applications
- Add batching, retries, or encryption
- Filter or redact sensitive data
- Route telemetry to multiple destinations
- Collect host-level metrics in addition to application telemetry

## Prerequisites

- A Linux or Windows system where the Collector can be installed
- Permission to install packages or services on that system

## Install on Linux

OpenTelemetry Collector releases are available in multiple package formats and architectures. See the official [Collector releases](https://github.com/open-telemetry/opentelemetry-collector-releases/releases) for the latest packages.

Every Collector release includes Debian and RPM packages for common Linux architectures. After installation, the default configuration is typically available at `/etc/otelcol-contrib/config.yaml`.

<hint type="info">
  Installing the Collector with the system package manager is recommended because it sets up the service automatically.
</hint>

### Debian-Based Systems

Example installation for `amd64`:

```bash
sudo apt-get update
sudo apt-get -y install wget systemctl
wget https://github.com/open-telemetry/opentelemetry-collector-releases/releases/download/v0.116.0/otelcol-contrib_0.116.0_linux_amd64.deb
sudo dpkg -i otelcol-contrib_0.116.0_linux_amd64.deb
```

Example installation for `arm64`:

```bash
sudo apt-get update
sudo apt-get -y install wget systemctl
wget https://github.com/open-telemetry/opentelemetry-collector-releases/releases/download/v0.116.0/otelcol-contrib_0.116.0_linux_arm64.deb
sudo dpkg -i otelcol-contrib_0.116.0_linux_arm64.deb
```

### RPM-Based Systems

Example installation for `amd64`:

```bash
sudo yum update
sudo yum -y install wget systemctl
wget https://github.com/open-telemetry/opentelemetry-collector-releases/releases/download/v0.116.0/otelcol-contrib_0.116.0_linux_amd64.rpm
sudo rpm -ivh otelcol-contrib_0.116.0_linux_amd64.rpm
```

Example installation for `arm64`:

```bash
sudo yum update
sudo yum -y install wget systemctl
wget https://github.com/open-telemetry/opentelemetry-collector-releases/releases/download/v0.116.0/otelcol-contrib_0.116.0_linux_arm64.rpm
sudo rpm -ivh otelcol-contrib_0.116.0_linux_arm64.rpm
```

## Install on Windows

1. Open the official [Collector releases](https://github.com/open-telemetry/opentelemetry-collector-releases/releases).
2. Download the Windows installer for the required architecture.
3. Run the installer as an administrator.
4. Complete the installation wizard.

The `otelcol-contrib.exe` binary is also available in release artifacts if you want to run it directly after unpacking.
