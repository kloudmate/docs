OpenTelemetry is the primary standard KloudMate supports for collecting and transporting logs, metrics, and traces.

Use this section to understand the OpenTelemetry model, decide when to use the Collector, and configure it to send telemetry to KloudMate.

:::note
The [KloudMate Agent](../kloudmate-agent/) embeds and manages an OpenTelemetry Collector for you, so you usually do not configure the Collector by hand. If you need to hand-tune it or add a custom receiver, see [Advanced configuration](../kloudmate-agent/advanced-configuration/).
:::
