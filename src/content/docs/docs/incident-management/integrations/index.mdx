Integrations are endpoints that accept alerts from external systems and turn them into incidents inside KloudMate.

Each integration belongs to a service and can use a dedicated escalation policy or inherit the service default.

## Integrations Overview

Open **Incident Management -> Integrations** to view the list of configured integrations.

![image](./images/integrations-1.jpeg)

Each row shows the integration name, description, type, related service, and assigned escalation policy.

:::note
  Each integration can use only one escalation policy at a time.
:::

## Integration Details

Open any integration to:

- Enable or disable it
- Copy the integration URL
- Edit its configuration
- Archive it
