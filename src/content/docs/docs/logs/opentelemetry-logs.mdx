OpenTelemetry is a vendor-agnostic observability framework that can be used to generate, collect, and route telemetry data, including application and system logs. You can instrument your applications or services with OpenTelemetry to collect logs and export them to KloudMate.

Sending Logs From OpenTelemetry to KloudMate
---------

If your application is instrumented using **OpenTelemetry**, logs can be exported to KloudMate through**APM Instrumentation**.

APM Instrumentation enables applications to generate and export OpenTelemetry-formatted logs directly to KloudMate. This method is recommended when you are instrumenting application code and require structured, context-rich logs.

Refer to the [APM Instrumentation](../../traces/apm/manual-instrumentation/) documentation for language-specific configuration and export settings.

***

After ingestion, logs can be accessed in the [Logs](https://app.kloudmate.com/logs) section of KloudMate.

Refer to the [Log Explorer](../log-explorer/) documentation to search, filter, and analyze ingested logs.
