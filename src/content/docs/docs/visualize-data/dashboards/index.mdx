KPI metrics come in all shapes and sizes and are often specific to businesses and applications. Pre-defined default metrics cannot always capture what matters most to your team. KloudMate’s custom metric dashboards let you cut through the noise and focus on only the metrics relevant to your application and business.

Navigate to **Dashboards** from the left navigation menu to view all your existing dashboards and folders.

![image](./images/dashboards-overview-1.png)

The Dashboards screen lists every dashboard with its name, description, and tags. Search for a dashboard or folder by name with the search bar. Use the **List** and **Folders** toggle to switch between one flat list and a view grouped by folder. In **List**, a dashboard that's in a folder shows the folder name before its own.

From the more options (⋯) icon on a dashboard, you can **Move to folder**, **Share**, or **Delete** it. Sharing offers both a copyable public link and the dashboard's JSON. See [Sharing a Dashboard](./dashboard-details/#sharing-a-dashboard).

### Tag dashboards

Click a dashboard's **Tags** cell to add a tag, or to create a new one. To show only the dashboards with certain tags, click **Tags** in the toolbar and pick one or more. Tags aren't case-sensitive and are saved in lowercase, so `Prod` and `prod` are the same tag.

### User Permissions

| **Role**      | **Permissions**                                |
| ------------- | ---------------------------------------------- |
| **Admin**     | Create, edit, or delete dashboards and folders. Turn a public link on or off. |
| **Developer** | Create, edit, or delete dashboards and folders |
| **Viewer**    | View dashboards and folders only |

## Dashboard Folders

Folders help you organize related dashboards in one place, making it easier to navigate and manage dashboards across teams or services.

1. Click the arrow next to **Create Dashboard** at the top of the Dashboards screen, then click **Create folder**.

![image](./images/dashboards-overview-2.png)

2. Enter a **Name** and an optional **Description**, then click **Create**.

Switch to **Folders** to see the new folder. Click the arrow next to it to expand and view the dashboards inside. Dashboards that aren't in a folder are listed under **Ungrouped**, at the bottom.

![image](./images/dashboards-overview-1.jpeg)

To put a dashboard in a folder, open its more options (⋯) icon, click **Move to folder**, and pick the folder. Pick **Ungrouped** to take it out of a folder.

Use a folder's more options (⋯) icon to **Edit folder** or **Delete folder**. Deleting a folder doesn't delete its dashboards. They move to **Ungrouped**.

:::info
Creating a folder is not mandatory. Standalone dashboards do not need to be added to a folder.
:::

### Public Dashboards

Sharing a dashboard publicly lets you give read-only access to people outside your workspace, for example, stakeholders or external teams, without requiring them to log in to KloudMate.

Click **Public Dashboards** at the top of the Dashboards screen to view all dashboards you have shared publicly. 

![image](./images/dashboards-overview-3.png)

The list shows the dashboard name, who shared it, and whether the link is currently active.

From this screen you can:

- **Copy link:** Copy the shareable URL to send to others.
- **View:** Open the public dashboard to preview what others will see.
- **Delete:** Revoke access. Deleting the link will make it stop working immediately.

## Importing a Dashboard

You can import a dashboard from its JSON definition, so you don't have to build it from scratch. For example, you can export a dashboard from one workspace and import it into another. To get the JSON of an existing dashboard, see [Sharing a Dashboard](./dashboard-details/#sharing-a-dashboard).

1. Copy the dashboard's JSON definition.

2. In KloudMate, click the **Import** button at the top-right of the Dashboards screen, paste the copied JSON into the Import Dashboard dialog, and click **Submit**.

![image](./images/dashboards-overview-4.png)

The dashboard will appear in your Dashboards list, ready to open and use with your data.

To create, update, or delete dashboards from a script instead, or to read the JSON format, see [Dashboard JSON and API](./dashboard-json-and-api/).
