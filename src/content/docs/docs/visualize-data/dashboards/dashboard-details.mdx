Opening a dashboard takes you to the Dashboard Details view where all your panels are displayed together. Every panel updates with the selected time range and refresh setting.

![The Kubernetes cluster overview dashboard with Health stat panels and node CPU and memory charts](./images/dashboard-details-1.png)

## Toolbar

The toolbar at the top provides the following controls:

- **Panel list:** Opens a dropdown listing all panels on the dashboard, grouped by section. Click a panel to jump to it without scrolling.

![The panel list open, showing panels grouped under the Health and Nodes sections](./images/dashboard-details-1.jpeg)

- **Time range picker:** Sets the time window applied to all panels. Choose a relative option, type one such as `15m` or `1h` in the **Relative time** field, or use **Start & End time** to set a custom range. You can also set the **Time zone**.

![The time range picker open, with the Relative time field, preset ranges, Start & End time, and Time zone](./images/dashboard-details-2.jpeg)

- **Refresh icon:** Manually refreshes all panels to pull the latest data.
- **Refresh interval dropdown:** Sets an automatic refresh interval so the dashboard stays current. 

![The refresh interval menu open, with Off and intervals from 5s to 30m](./images/dashboard-details-3.jpeg)

- **Export:** Exports the dashboard.
- **Share:** Opens the Share Dashboard dialog, with options for a public link or a copy of the dashboard's JSON.
- **Fullscreen:** Expands the dashboard to fullscreen view.
- **Edit:** Enters edit mode to modify the dashboard and its panels.

## Viewing Alerts in Dashboards

KloudMate integrates alerts directly into your dashboard visualizations, providing immediate context on system health alongside your metrics.

![The Linked Alerts bell in the dashboard toolbar](./images/dashboard-details-5.png)

- **Linked Alerts:** Click the bell icon in the toolbar to open the Linked Alerts drawer, which lists every alert linked to a panel in the dashboard.
- **Panel Alert Indicators:** If a panel is linked to an alert and the alert is currently **Firing**, a status indicator will appear on the panel header.
- **Alerts Drawer:** Clicking on an alert indicator opens the Alerts Drawer without leaving the dashboard context. This drawer displays information for alerts in the **Firing** state:
  - The current evaluation state of the alert.
  - The conditions that triggered it.

## Sharing a Dashboard

To open the Share Dashboard dialog, click **Share** in the dashboard's toolbar, or in the more options (⋯) menu in the dashboard list.

![The Link tab of the Share dialog, with Enable public sharing, Allow time range selection, Theme, and Time range](./images/dashboard-details-2.png)

### Public link

Generates a link that anyone can use to view the dashboard without logging in to KloudMate.

- **Enable public sharing:** Toggle this on to activate the public link.
- **Allow time range selection:** Toggle this on to let viewers change the time range when viewing the shared dashboard.
- **Theme:** Sets the theme the dashboard opens in from a public link: **System**, **Light**, or **Dark**. **System** follows the viewer's device setting.
- **Time range:** Sets the default time range viewers will see when they open the shared link.
- **Variables:** Shown when the dashboard has variables. Picks the value of each variable for the public link. Viewers can't change them. A public link opens on the values picked here, whatever the dashboard's defaults or anyone's own picks. A variable you don't pick here uses its default.

Click **Save** to apply the settings. The shared link can be managed from the **Public Dashboards** page.

A public dashboard draws no annotations, and its panel menu has no **Create alert**.

### Export

Open the **Export** tab to get the dashboard as YAML, then click **Copy** or **Download**. Import the file into another workspace to recreate the dashboard with the same layout and no manual rebuild. See [Importing a Dashboard](../#importing-a-dashboard) and [Config as code](../../../platform/config-as-code/).
