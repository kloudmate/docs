Dashboards and Explore turn your telemetry into charts and tables. Use a dashboard for a lasting view of the infrastructure and application metrics you check every day, and Explore for one-off queries while you troubleshoot an incident.

## In This Section

- **[Dashboards](./dashboards/)**
  Build lasting views of your most important metrics. A dashboard combines panels, such as time series charts, bar charts, lists, and stats, on one page. You can create one from scratch or start from a template for common setups like Kubernetes or database monitoring.

  To build panels, see [Adding a Panel](./dashboards/adding-a-panel/), [Queries and Data Sources](./dashboards/adding-a-panel/queries-and-data-sources/), and [Panel Options](./dashboards/panel-options/). To work with whole dashboards, see [Annotations](./dashboards/annotations/), [Dashboard variables](./dashboards/dashboard-variables/), and [Dashboard JSON and API](./dashboards/dashboard-json-and-api/).

- **[Explore](./explore/)**
  Query metrics, logs, and traces on the fly, try different aggregations, and check the result before you save the query as a dashboard panel.
