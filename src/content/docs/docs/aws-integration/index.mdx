KloudMate provides native integrations for Amazon Web Services (AWS) that allow you to seamlessly pull metrics, logs, and traces into your observability pipelines. By connecting your AWS account, you can monitor your infrastructure and serverless workloads without having to instrument every individual component by hand.

## How it Works

KloudMate connects to your AWS environment securely using a cross-account IAM role, provisioned via an automated AWS CloudFormation template. This ensures that KloudMate only receives the permissions strictly necessary to read telemetry data and metadata, maintaining a secure, read-only posture.

Once connected, KloudMate can automatically discover AWS resources and begin ingesting their associated metrics and logs.

## Key Capabilities

- **Automatic Resource Discovery**: Quickly discover and monitor supported AWS resources, starting with AWS Lambda.
- **Centralized CloudWatch Logs**: Subscribe to existing CloudWatch Log Groups directly from the KloudMate dashboard and forward them into the centralized Log Explorer.
- **Serverless Observability**: Get out-of-the-box dashboards and metrics (such as invocations, errors, cold starts, and memory usage) for AWS Lambda workloads.
- **Direct Lambda Telemetry**: Push logs, metrics, and traces straight from a function with the [Lambda Telemetry Extension](./lambda-telemetry-extension/) layer — no CloudFormation stack or CloudWatch subscription required.
