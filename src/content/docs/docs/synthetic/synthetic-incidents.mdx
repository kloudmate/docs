title: "Synthetic Incidents"
description: "Review incidents opened when synthetic monitors fail."
---
The 'Incidents' page consolidates all incidents from monitors created within the Synthetic monitoring module, providing centralized visibility into downtime events, across all monitors.

**The Incidents Overview Table**

The page displays a table summarizing all incidents for quick analysis:

- **Monitor**
  Identifies the specific monitor where the incident originated.
- **Cause**
  Details the root cause of the incident detected in that monitor.
- **Started At**
  Timestamp when the incident was first detected.
- **Resolved At**
  Timestamp when the incident was resolved, or indicates if still ongoing.
- **Duration** Total time period the incident remained active.***
