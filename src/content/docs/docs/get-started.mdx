# Sending Data to KloudMate

You can use the following three ways to send data to KloudMate:

## 1. **Send Data Using KloudMate Agents**



  

    ### [KloudMate Agents](./km-agent/index.mdx)

    Click here for installation steps and environment-specific setup guides.
  



## 2. Send Data via OpenTelemetry

OpenTelemetry provides a vendor-agnostic approach to receiving, processing, and exporting telemetry data. You can use **either **of the following ways to send data to KloudMate via OpenTelemetry:



  

    ### [Using OpenTelemetry Collector](./opentelemetry/index.mdx)

    Click here if you are already running an OpenTelemetry collector and prefer to keep using it to send data to KloudMate.
  



## 3. Send Data using Prometheus Integration

You can send your Prometheus metrics to KloudMate by configuring the OpenTelemetry Collector as a receiver for Prometheus data. This allows you to collect, process, and export all your Prometheus metrics to KloudMate for unified monitoring and alerting. 



  

    ### [Using Prometheus Integration](./metrics/infrastructure/index.mdx)

    Click here for step-by-step instructions to configure Prometheus monitoring and send your metrics to KloudMate.
  



## 4. Send Data Using AWS Integration

Using AWS integration to send data to KloudMate involves connecting your AWS account to KloudMate. It doesn't require any code instrumentation or agent installation. Once the integration is complete, KloudMate will use CloudWatch to pull logs and data for the synced services of the connected AWS account.



  

    ### [Using AWS Integration](./setting-up-kloudmate.mdx#daozk)

    Click here if you want to connect your AWS account to KloudMate to monitor your AWS services and resources.
  



## 5. Send Data Using Azure Integration 
Integrate Azure Monitor with KloudMate using the **OpenTelemetry Receiver**. This integration allows you to scrape telemetry data from Azure Monitor resources and send it to KloudMate for centralized monitoring and analysis.



  

    ### [Using Azure Integration](./metrics/infrastructure/index.mdx)

    Click here to integrate your Azure account with KloudMate and monitor your Azure resources.
