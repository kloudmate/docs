KloudMate documents database metrics under the dedicated [Database Monitoring](../../database-monitoring/) section rather than duplicating setup instructions inside the metrics area.

Use those guides when you want to:

- monitor MySQL, PostgreSQL, MSSQL, Redis, MongoDB, OracleDB, or other supported databases
- collect receiver-based database metrics through the KM Agent
- configure deeper query and execution-plan visibility with [Direct Database Monitoring](../../database-monitoring/direct-database-monitoring/)
