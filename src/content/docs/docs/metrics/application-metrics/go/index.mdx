Use the same OpenTelemetry SDK setup you use for Go traces to export metrics into KloudMate.

## Recommended Setup

Follow the [Go manual instrumentation guide](../../../traces/manual-instrumentation/go/) and configure OTLP export to KloudMate through the KloudMate Agent or an OpenTelemetry Collector.

## What You Can Expect

Go telemetry commonly includes:

- Request duration and throughput metrics
- Error metrics
- Go runtime metrics such as goroutines, GC activity, and memory usage
