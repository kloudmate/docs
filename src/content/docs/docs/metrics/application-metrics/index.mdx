Application metrics help you monitor how instrumented services behave at runtime, including request volume, latency, error counts, process health, and language runtime statistics.

KloudMate receives these metrics through the same OpenTelemetry SDK and OTLP exporter setup you use for traces and logs. In practice, this means you usually do not need a separate metrics-only installation flow for each language.

## How Application Metrics Reach KloudMate

1. Instrument your application with an OpenTelemetry SDK or agent.
2. Configure OTLP export to the KloudMate Agent or an OpenTelemetry Collector.
3. Enable metric export alongside traces and logs.
4. Query the emitted metrics in [Explore](../explore/) or build dashboards from them.
