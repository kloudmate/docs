Use the same OpenTelemetry SDK setup you use for .NET traces and logs to export metrics into KloudMate.

## Recommended Setup

Follow the [.NET manual instrumentation guide](../../../traces/manual-instrumentation/dotnet/) and configure OTLP export to KloudMate through the KloudMate Agent or an OpenTelemetry Collector.

## What You Can Expect

.NET telemetry commonly includes:

- Request latency and throughput metrics
- Error metrics
- Runtime metrics such as GC, memory, and thread-pool activity
