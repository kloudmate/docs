Use the same OpenTelemetry SDK setup you use for Node.js traces to export metrics into KloudMate.

## Recommended Setup

Follow the [Node.js manual instrumentation guide](../../../traces/manual-instrumentation/node-js/) and make sure your OTLP exporter is configured to send telemetry to KloudMate through the KloudMate Agent or an OpenTelemetry Collector.

## What You Can Expect

Depending on your instrumentation and runtime libraries, Node.js metrics can include:

- Request and response duration metrics
- Throughput and error metrics
- Node.js runtime metrics
- Framework and dependency metrics emitted by auto-instrumentation
