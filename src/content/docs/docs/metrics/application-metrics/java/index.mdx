Use the same OpenTelemetry SDK or Java agent setup you use for traces to send metrics to KloudMate.

## Recommended Setup

Follow the [Java manual instrumentation guide](../../../traces/manual-instrumentation/java/) and configure OTLP export to KloudMate through the KM Agent or an OpenTelemetry Collector.

## What You Can Expect

Java telemetry commonly includes:

- Request latency and error metrics
- JVM memory, GC, and thread metrics
- Framework and dependency metrics emitted by instrumentation libraries
