Infrastructure monitoring in KloudMate gives you visibility into the health, performance, and capacity of the systems your applications run on.

This section covers common infrastructure ingestion paths, whether you are monitoring a single server, a Kubernetes cluster, a Prometheus deployment, or a virtualized environment.

## What You Can Monitor

- Hosts and virtual machines
- Kubernetes clusters and workloads
- Prometheus-exported metrics
- VMware vCenter environments
- Cloud resources through AWS and Azure integrations
