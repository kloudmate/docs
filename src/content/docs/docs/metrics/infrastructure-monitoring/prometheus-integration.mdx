---
title: "Prometheus Integration"
description: "Ingest Prometheus metrics into KloudMate through an OpenTelemetry Collector."
---
Use this integration when your workloads already expose Prometheus metrics and you want KloudMate to ingest them without changing application code.

KloudMate does not scrape Prometheus directly. Instead, you configure an OpenTelemetry Collector with the Prometheus receiver and export the collected metrics to KloudMate.

## Prerequisites

1. Install and run the [OpenTelemetry Collector](../../opentelemetry/installing-the-opentelemetry-collector/).
2. Obtain your KloudMate API key.
3. Ensure you can access the Prometheus configuration or know the scrape targets you want the Collector to use.

## Step 1: Define the Prometheus Receiver

Add a Prometheus receiver to the Collector configuration. You can copy scrape jobs from your existing Prometheus configuration or define a smaller metrics-only subset for KloudMate.

```yaml
receivers:
  prometheus:
    config:
      scrape_configs:
        - job_name: otel-collector
          scrape_interval: 5s
          static_configs:
            - targets: ["0.0.0.0:8888"]
        - job_name: kubernetes-pods
          kubernetes_sd_configs:
            - role: pod
          relabel_configs:
            - source_labels: [__meta_kubernetes_pod_annotation_prometheus_io_scrape]
              regex: "true"
              action: keep
          metric_relabel_configs:
            - source_labels: [__name__]
              regex: "(request_duration_seconds.*|response_duration_seconds.*)"
              action: keep
```

<hint type="info">
  Validate indentation carefully when copying `scrape_configs` into the Collector configuration.
</hint>

## Step 2: Add the KloudMate Export Pipeline

Configure the exporter and metrics pipeline:

```yaml
processors:
  batch:
    send_batch_size: 5000
    timeout: 10s

exporters:
  otlphttp:
    endpoint: "https://otel.kloudmate.com:4318"
    headers:
      Authorization: xxxxxxxx

service:
  pipelines:
    metrics:
      receivers: [prometheus]
      processors: [batch]
      exporters: [otlphttp]
```

## Step 3: Restart the Collector

```bash
sudo systemctl restart otelcol-contrib
sudo systemctl status otelcol-contrib
```

## Step 4: Validate in KloudMate

After the Collector restarts:

- open [Explore](../explore/)
- query one of the scraped Prometheus metrics
- build dashboards or alarms once the data is visible
