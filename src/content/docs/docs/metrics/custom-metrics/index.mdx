Custom metrics let you track business and application signals that auto-instrumentation does not produce on its own, such as checkout counts, queue depth, tenant-level usage, or feature-specific latencies.

KloudMate receives custom metrics through the same OpenTelemetry SDK and OTLP exporter flow used for traces and standard application metrics.

## Typical Flow

1. Set up OpenTelemetry instrumentation in your application.
2. Initialize a Meter Provider.
3. Create instruments such as counters, histograms, or gauges.
4. Record measurements in the code paths you care about.
5. Export the telemetry to KloudMate through the KloudMate Agent or an OpenTelemetry Collector.

## When to Use Custom Metrics

Use custom metrics when you need to measure:

- Business events such as signups, checkouts, or billing actions
- Tenant or customer-specific workload patterns
- Queue depth, job duration, or batch throughput
- Internal service states that are not visible through auto-instrumentation
