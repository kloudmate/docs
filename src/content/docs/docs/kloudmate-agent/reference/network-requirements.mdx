Before you install the agent on a network with restricted outbound access, allowlist the URLs below. Without them, the agent cannot download, check in, or send telemetry.

## Required URLs

| URL | Purpose |
|---|---|
| `otel.kloudmate.com` | The telemetry endpoint the agent's collector sends metrics, traces, and logs to. |
| `api.kloudmate.com` | The KloudMate API the agent uses to check in, fetch configuration, and report status. |
| `ghcr.io` | GitHub Container Registry, where the agent and collector container images are hosted (Docker and Kubernetes installs). |
| `pkg-containers.githubusercontent.com` | Backing storage for `ghcr.io` image layers. |
| `github.com` | Used by the install script to download the agent. |
| `api.github.com` | Used for agent update checks. |

All of these are outbound, HTTPS connections initiated by the agent or collector; no inbound access is required.
