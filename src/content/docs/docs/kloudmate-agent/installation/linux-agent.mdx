## What the Linux Agent Monitors

After installation, the agent sends telemetry data to KloudMate, enabling unified monitoring of system health and issue investigation.

Key capabilities:

- Monitoring CPU, memory, disk, and network usage
- Tracking performance trends over time
- Detecting resource bottlenecks
- Collecting and analyzing system and application logs
- Visualizing data with dashboards
- Creating alerts for critical conditions

## Install Agent

**Step 1:** Navigate to the **Settings → Agents** section in your KloudMate account.

**Step 2:** Select **Linux** from the list of available integrations.

**Step 3:** Copy and run the Linux agent install command in your terminal to download and install the agent.

![image](./images/linux-agent-1.png)

**Step 4:** Run the agent status command to check if the agent is active.

![image](./images/linux-agent-2.png)

**Step 5:** Execute the "Check Logs" command to confirm the agent is functioning correctly.

![image](./images/linux-agent-3.png)

## **Log Integration**

By default, the KloudMate Agent collects basic system logs (the systemd journal).

To collect your own application log **files**, use log monitoring: from the agent's **Logs** tab you point the agent at a folder and file-name pattern and choose how to parse each line (plain text, JSON, or a regular expression). Multiline grouping, for stack traces or pretty-printed JSON, is a modifier you apply on top of any format, and you can preview the parsed records before you save. See [Log monitoring](../../log-monitoring/).

For a hand-written `filelog` receiver in manual mode, see [Collect File Logs with KloudMate Agent](../../../logs/collect-file-logs/).

## Configuration and next checks

New agents start in **managed mode**, with a default of host metrics, logs, and the eBPF baseline. You review and change what is collected from the web interface, without editing files on the host. See the [configuration model](../../concepts/config-model/).

After the agent is running, confirm the baseline and explore what it found:

- Host metrics and logs start flowing automatically. See [Host metrics and logs](../../baseline/host-metrics-and-logs/).
- On a supported Linux kernel (4.14 or newer), the [eBPF baseline](../../ebpf-observability/) turns on automatically and adds RED metrics and a service map.
- Open the **Discovered Services** list for the host to see what the agent found and instrument a service. See [Discovery](../../concepts/discovery/).
