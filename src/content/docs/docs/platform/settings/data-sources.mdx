Use **Data Sources** to connect AWS accounts, review sync settings, and control which resources are imported into KloudMate.

## Connect an AWS Account

KloudMate can connect multiple AWS accounts and begin ingesting supported logs, metrics, and traces after setup.

To connect a new account, follow [AWS Account Setup](../../aws-integration/account-setup/).

## Manage Connected Accounts

Open **Settings -> Data Sources** to view all connected AWS accounts.

From this page, you can:

- Add additional AWS accounts
- Open account details
- Review or update sync settings
- Access CloudWatch log subscription controls
- Remove an AWS account

![image](./images/data-sources-1.png)

Enter the AWS account name and follow the on-screen setup flow when adding a new account.

![image](./images/data-sources-2.png)

## Review Sync Settings

The data sources page shows every connected AWS account.

![image](./images/data-sources-3.png)

Open the account details screen for the AWS account you want to manage.

![image](./images/data-sources-4.png)

Use the account settings view to control sync behavior and review CloudWatch log options.

![image](./images/data-sources-5.png)

Enable or disable sync for individual services and regions based on what you want KloudMate to monitor.

![image](./images/data-sources-6.png)

## Tag Filtering

Tag filtering lets you limit syncing to AWS resources that match specific tags.

1. Open the sync settings screen.
2. Click **Add Tags ** under ** Tag Filtering**.

![image](./images/data-sources-7.png)

3. Enter the tags you want to use.
4. Save the configuration.

![image](./images/data-sources-8.png)

If tags are already configured, use the edit action to update or remove them.

![image](./images/data-sources-9.png)
