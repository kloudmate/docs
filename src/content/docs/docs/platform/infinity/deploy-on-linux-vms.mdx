Use this deployment model when you want to run KloudMate Infinity on Linux virtual machines instead of Kubernetes.

## Infrastructure Prerequisites

- A domain name with a wildcard SSL certificate
- SMTP credentials for sending email notifications
- A Stripe account if online billing is required

## VM 1 Requirements

- A Linux machine running **Ubuntu**
- Network access to the applications or devices you want to monitor
- Port `4318` exposed
- `8` CPU cores
- `16 GB` memory
- `1 TB` storage
- An active internet connection

## VM 2 Requirements

- A Linux machine running **Ubuntu**
- Port `4318` exposed
- `2` CPU cores
- `4 GB` memory
- `100 GB` storage
- An active internet connection

After completing the prerequisites, [contact KloudMate](https://www.kloudmate.com/contact) to proceed with deployment.
