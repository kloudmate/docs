**KloudMate Infinity** is KloudMate's self-hosted deployment option for organizations that want to run the platform on their own infrastructure.

Depending on your environment and scale requirements, you can deploy KloudMate Infinity on:

- Linux virtual machines
- A Kubernetes environment such as EKS, AKS, GKE, or a self-hosted cluster

<hint type="info">
  KloudMate Infinity is different from the standard KloudMate SaaS offering.
</hint>
