Use this deployment model when you want to run KloudMate Infinity on Kubernetes-managed infrastructure.

## Infrastructure Prerequisites

- A running Kubernetes cluster, whether self-hosted or managed through services such as EKS, AKS, or GKE
- Kubernetes version `>= 1.22`
- `x86-64/amd64` workloads only
- Helm version `>= 3.14.3`
- Persistent volumes or storage classes with at least `1 TB` of storage
- A Kubernetes `LoadBalancer` if you plan to provision multiple nodes
- A domain name with a wildcard SSL certificate
- SMTP credentials for sending email notifications
- A Stripe account if online billing is required
- `kubectl` access to the cluster

## Minimum Sizing

| Resource | Minimum / POC | Minimum Production |
| -------- | ------------- | ------------------ |
| Nodes | 3 | 5 |
| CPU | 8 cores | 16 cores |
| Memory | 16 GB | 32 GB |
| Storage | 500 GB | 1 TB |

## Moderate Workload Cluster

This setup is suitable for approximately `1 TB` of monthly ingestion.

| Component | Node Count | vCPUs Per Node | RAM Per Node | Storage Per Node |
| --------- | ---------- | -------------- | ------------ | ---------------- |
| Control Plane | 3 | 4-8 | 8-16 GB | 50 GB |
| Data Nodes | 2 | 8-16 | 32-64 GB | 1-2 TB NVMe SSD |

## High Workload Cluster

This setup is intended for very high ingestion rates and larger production deployments.

| Component | Node Count | vCPUs Per Node | RAM Per Node | Storage Per Node |
| --------- | ---------- | -------------- | ------------ | ---------------- |
| Control Plane | 3 | 4 | 8-16 GB | 50 GB |
| Data Nodes | 4 | 16-32 | 64-128 GB | 1-2 TB NVMe |

After completing the prerequisites, [contact KloudMate](https://www.kloudmate.com/contact) to proceed with deployment.
